### Mis Proyectos Destacados

**Chatbot NovaTech — Asistente Virtual de RRHH** *(Proyecto Final AWS re/Start)*
Asistente virtual basado en RAG que responde consultas de RRHH sobre políticas internas en español, citando la política formal por su nombre. Memoria multi-turno con compactación de contexto, guardrails de doble capa contra la alucinación y reintentos con backoff exponencial. 44 tests automatizados (unitarios, integración y E2E).
**[Ver Repositorio](https://github.com/CarMalNie/chatbot_empresarial_rrhh)** | **[Video Demo](https://youtu.be/sJjohn72Up4)**

**Aplicación Web "Gestor Químico" — En Producción**
Plataforma Full Stack para gestionar una base de datos de compuestos químicos, con un motor que calcula el peso molecular a partir de fórmulas IUPAC complejas (incluidos hidratos), integración con la API pública de PubChem y visualización de estructuras 2D. Autenticación completa (MFA TOTP opcional), más de 130 tests integrados a CI y despliegue reproducible en PythonAnywhere.
**[Demo en Vivo](https://carmalnie.pythonanywhere.com/)** | **[Ver Repositorio](https://github.com/CarMalNie/Gestor_Quimico)** | **[Video Demo](https://youtu.be/-5b_5_unwvo)**

**Sitio Web Estático - Ciberseguridad**
Sitio web informativo (HTML/CSS/JavaScript/Bootstrap) sobre conceptos fundamentales de ciberseguridad, enfocado en maquetación responsiva.
**[Ver Sitio](https://carmalnie.github.io/Sitio-Estatico-Ciberseguridad/)** | **[Ver Repositorio](https://github.com/CarMalNie/Sitio-Estatico-Ciberseguridad)** | **[Video Demo](https://youtu.be/PdunHiWGRf8)**
